## 結論

静的HTMLなら[Bulma](https://bulma.io/)が一番よさげ。

## 検討対象

Copilotに聞いたり、Qiitaを見たりしながら候補を選びました。

これまでWordpressだったりBlazorだったりの内部的に使っていたことはありましたが、
単体としてCSSフレームワークを使ったことはなかったので、選定が偏っているかもしれません。

個人的に使っている端末が時間帯でライトモード / ダークモードを切り替える設定にしており、自分のサイトも両対応がいいです。
そうなると、必然的に2000年代のインターネットデザインがとれないので、新し目のフレームワークを選ぶしかないです。

### Bootstrap

公式サイト：[Bootstrap](https://getbootstrap.jp)

旧Twitter製。機能豊富で世界で一番使われているらしい。javascriptのライブラリつきで、カスタマイズ性にも優れる。
Blazorの標準テンプレートでも使っているので静的ジェネレーターでの使用も特に問題もなさそう。

選ばなかった理由は完全に逆張り。とはいえ、Fluent UIを試した時点で純粋CSSフレームワーク探しをすることになったので結果オーライ。

### Fluent UI

公式サイト：[Fluent UI](https://developer.microsoft.com/en-us/fluentui#/)

Microsoft製。重い。Blazorコンポーネントもある。
第一候補でプロトタイプはこれで作成を進めていたものの、残念なことに自作ジェネレーターで使うと動作が怪しかった。
おそらくjavascriptの読み込みに問題があるものと思われる。流石に使い方が完全に想定外だろうし、原因究明するほどでもなかったのでそっ閉じ。

ここから、方針転換してBlazorやjavascriptに頼らない純粋CSSフレームワークを探すようになる。

### Pure CSS

公式サイト：[Pure](https://pure-css.github.io)

Yahoo!製。軽量。
デザインがカラフルで性に合わないので却下。WEBの世界なので更新が2022年で止まっているのも気になるところ。
世界的なシェアの割には日本語情報が微妙に少ないのもよくわからない。まだAnt Design（諸事情で検討外）のほうが見かける気がする。

## Spectre.css

公式サイト：[Spectre.css](https://picturepan2.github.io/spectre/)

軽量。
事実上の第二候補として途中まで採用しながら作成を進めたものの、カラーカスタマイズのためにリビルドが必要なことが判明。
CSSトークンでの設定がないので不便なので、気に入ってはいたものの最終的に却下となる。

### Bluma

公式サイト：[Bluma](https://bulma.io)

軽量と呼ばれているが、たぶんjavascriptがないことによるもので、本体サイズは別に小さくなかった。実際、minimalでもbootstrapt minimalと大して変わらない。
理由は後述しますが、最終的に本命として採用になりました。使い勝手もデザイン性も良かったと思います。

## Blumaについて

### javascriptレス

作成したジェネレーターがRazor構文を使用する関係で、javascriptフレームワークは使用したくない。~~最初Fluent UIで開発を始めてしまっていたが~~
モバイル時のハンバーガーメニューのみjavascriptを使用するが、これはとても小さく後入れなので気にならない。

どうせコメント欄は他のスクリプトのフレームワークを使用するので、サイトに動的な要素はほとんど必要ない。

純粋なHTML + CSSならファイル自体の容量が多少大きくても動作が重たくなるなどの問題が起きにくいし、表示も早い。

### CSS変数

CSS変数によるメインカラーやフォントの設定が可能。
リビルドするのと違い、変数に対する破壊的変更点がない限りバージョンアップ追従時のメンテナンスが不要。

### 似通ったデザインになる

人はオリジナリティを発揮するとダサくなる。デザインセンスを開拓するごく少数の天才たち以外は先人に続いたほうがいい。
逆にいえばこれはデザインセンスに自身がありオリジナリティを出したい人にはデメリット。

### CDN

CDNに置かれているバージョンが古いようで、最新版を使いたい場合はDLしたものをホスティングすることになる。
まあこれは時間が解決してくれるはず。
